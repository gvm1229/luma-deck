# PRAG Presentation Local AI Directives

This deck is moving toward Diana's sketchbook style.

- Treat the visual base as a blank white canvas using `gray-100` as the primary color and `blue-600` as the accent color.
- Do not add grid, graph-paper, HUD, technical scanline, cyber/sci-fi gradient, orb, or grid-like background decorations.
- If scribbles are added later, keep them organic and hand-drawn, not grid-like or technical.
- Every title must be bold, including slide titles, section titles, card titles, description box titles, and image captions that function as titles.
- After any slide visual/layout edit, including a single-slide edit, run a visual review test for the affected slide before claiming completion.
- Treat visible misalignment as a must-fix defect; aligned edges, consistent gaps, and stable baselines take priority over decorative variation.
- Keep slide-specific layout instructions in `slides.md` and visual styling in `style.css` unless the user asks otherwise.
